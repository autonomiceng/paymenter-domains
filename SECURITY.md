# Security

There is no released or implemented extension yet, and no supported release series.

Do not put registrar credentials, transfer authorization codes, customer contacts, payment records, or raw provider responses in a public issue or pull request. Use GitHub's private vulnerability reporting for this repository when available. If unavailable, contact the maintainer through their GitHub profile to arrange a private channel before sharing sensitive details.

Future security reports should identify the affected revision, impact, and a minimal synthetic reproduction. Keep real account and customer evidence private.
